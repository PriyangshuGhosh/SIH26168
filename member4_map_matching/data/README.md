# Member 4 offline map fixtures

| File | Role |
|---|---|
| `small_road_network.graphml` | Offline OSM extract (~400 m drive network around 12.9716, 77.5946). Committed so runtime/tests need no network. |
| `synthetic_grid.geojson` | Deterministic synthetic grid for unit/HMM tests (generated by `tools/build_synthetic_graph.py`). |
| `*.roadpack` | Portable road pack consumed by the C++ runtime (generated; do not invent coverage claims). |
| `*.sqlite` | Optional Python SQLite + R-tree DB (generated; gitignored). |

## Reproduce OSM extract (optional, requires network once)

```bash
python3 python/tools/extract_osm.py --lat 12.9716 --lon 77.5946 --radius-m 400 \
  --out data/small_road_network.graphml
```

## Build offline databases (no network)

```bash
python3 python/tools/build_synthetic_graph.py
python3 python/tools/build_road_database.py --graphml data/small_road_network.graphml
python3 python/tools/build_road_database.py --geojson data/synthetic_grid.geojson
```

Runtime map matching never downloads OSM.
