# Member 4 offline map fixtures

| File | Role |
|---|---|
| `small_road_network.graphml` | Offline OSM extract (~400 m drive network around 12.9716, 77.5946). Committed so runtime/tests need no network. |
| `synthetic_grid.geojson` | Deterministic synthetic grid for unit/HMM tests (generated by `tools/build_synthetic_graph.py`). |
| `*.roadpack` | Portable road pack consumed by the C++ runtime (generated; do not invent coverage claims). |
| `maps/regions/*.roadpack` | Installed region packs (OSM extract in-tree). |
| `maps/manifest.json` | Multi-region catalog. Select by WGS84 bounds, never a city name. |

OSM extract: OpenStreetMap, ODbL 1.0, © OpenStreetMap contributors. Small demo tile, not city-scale.

Live Overpass: `python/tools/extract_osm.py --lat ... --lon ... --catalog ...` (optional network).

Runtime map matching never downloads OSM.
