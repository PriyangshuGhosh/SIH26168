# Hardware evaluation (MODE A)

No board is recommended for purchase in this phase. Simulation is sufficient for the localization math.

Minimum **future** spec (class, not SKU): C-V2X OBU, decoded kinematic output, host interface (IP or serial), documented latency, India WPC/type-approval path for 5875–5905 MHz OBU rules.

What simulation **can** validate: validation, gating, relative-transfer math, covariance, no-V2X fallback, replay.

What it **cannot**: RF, congestion, 1609.2, OBU–phone integration, Android latency.
